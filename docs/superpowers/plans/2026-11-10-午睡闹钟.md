# 午睡闹钟实施计划

**目标：** 实现离线 Android 午睡闹钟，支持拉绳设定 1～45 分钟、后台助眠音乐和到点响铃。

**架构：** Kotlin、Jetpack Compose、Media3、DataStore 与 AlarmManager；会话状态持久化，系统负责到点调度。

**设计依据：** `午睡闹钟设计方案.md`。

## 约束与风险

- 首版仅 Android，同一时间只允许一个午睡会话。
- 时长以单调时钟计算，重启后使用保存的墙上时钟目标恢复。
- 拒绝权限、服务异常或调度失败必须明确提示。
- 强制停止、关机、厂商限制及重启期间不保证响铃。
- 拉绳需要无障碍替代操作，音乐需要可分发授权。

## 任务

1. 工程与拉绳：先测试时长边界，再实现 Compose 拉绳、加减按钮与预计唤醒时间。
2. 会话与调度：先测试会话状态、取消及过期事件，再实现 DataStore、AlarmManager 和重启恢复。
3. 音频：实现本地助眠音频、后台播放、音频焦点和到点闹铃；验证停止及重复触发。
4. 集成验证：运行单元测试与构建，在模拟器验证首页、权限、开始和停止流程；记录无法验证的设备场景。
